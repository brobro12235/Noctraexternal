NOCTRA 1.2.0 - Portable Windows x64 release

RUN
1. Extract the entire ZIP to a folder you can write to.
2. Open Noctra.exe. No installer or administrator elevation is requested.
3. Insert shows/hides the menu when the menu or Roblox has focus.
   Drag the header or resize the edges. X closes; _ minimizes.
4. Live modules start OFF. Preferences are saved only when you explicitly
   save a profile in Config. Profiles use %LOCALAPPDATA%\Noctra\profiles.

REQUIREMENTS
- 64-bit Windows 10/11 with a DirectX 11-compatible GPU/driver.
- No Visual Studio, CMake, Python or matching Visual C++ Redistributable is
  required by this build. The MSVC runtime is statically linked; standard
  Windows system libraries are still required.
- Internet access is needed for the optional Roblox profile avatar image.
  It uses public Roblox APIs without account passwords, API keys or cookies.

APPLICATION UPDATES
- This copy checks public GitHub Releases for brobro12235/Noctraexternal on
  normal launch. It does not poll continuously, install in the background,
  upload your data, or include a GitHub token.
- Misc / Version or Config / Version shows update results. Choose Download
  update, then Install and restart, and confirm. Save your profile first.
- Updates require a signed manifest, exact SHA-256/size and a newer release
  sequence. EXE updates require signatures; offset data is restricted to the configured HTTPS host, schema-validated and runtime-validated. A helper waits for
  the current copy to exit, replaces Noctra.exe and confirms new-menu startup.
  The previous EXE is retained in the adjacent Noctra-update-* backup folder.
- Keep the filename Noctra.exe and place it in a writable, non-junction folder.
  Other running copies may prevent replacement. No elevation is attempted.
- 1.0.0 copies need one manual upgrade; they did not include an updater.
- Checks require internet and a PUBLIC published release with update.json and
  Noctra.exe assets. A private/missing repository may look like no releases.
- Offsets are fetched for the detected Roblox client build from the configured
  HTTPS feed and cached beside Noctra.exe as offsets.json and offsets.version.
  Invalid, unavailable or runtime-incompatible data disables live features.
  This does not provide universal game, rig, team or character support.

COMPATIBILITY AND LIMITATIONS
- Live game data uses the matching build document. Builds missing from the
  feed, changed layouts, custom rigs/cameras and custom teams remain disabled by
  the existing runtime validation gates.
- Standard R6/R15 character geometry remains supported. Custom rigs/cameras
  and custom teams may not work. This is not universal game support.
- Experimental Phantom Forces adapter (place 292439477 only): bounded checks
  of anonymous replicated model geometry can provide boxes, tracers and
  distance labels. Final live rendering remains UNVERIFIED: the most recent
  inspected scene had no replicated models. Empty/changed layouts draw nothing.
- PF player identity, local-model ownership, health, teams and skeleton joints
  are not verified. Names/health/skeleton/aim controls are unavailable; aiming
  is blocked even with Team check off. Geometry may include allies, and a
  near-camera exclusion is not proof of reliable self filtering. No local
  avatar preview is available without validated local character data.
- Misc / Version and Config / Version show PF model/rejection counts. Use
  --diagnose to distinguish empty scenes from models rejected by validation.
- TTK custom-team membership is not verified. Team check blocks aiming when
  standard team data is unavailable; it does not identify TTK enemies.
- The avatar image is a STATIC profile thumbnail, not an animated or textured
  live 3D model and not necessarily an experience-modified outfit. Its ESP
  box/skeleton guides are approximate illustrations of the chosen style.
- No guarantee of undetected operation, account safety, or game-rule compliance
  is made. Use only where you have permission and comply with applicable rules.

TRUST AND SUPPORT
- This executable is UNSIGNED. Windows/security software may warn about it.
  Verify the SHA-256 supplied by the sender; do not disable security software.
- The application uses ordinary read-only Windows process access for game data
  and can send normal mouse input if Aim is explicitly enabled. No injection,
  kernel driver, memory writes or anti-cheat bypass is included.
- Test this release on your own PC before relying on it. It has not been tested
  on every hardware/Windows configuration or in a clean virtual machine.
- For troubleshooting, Noctra.exe --diagnose writes artifacts/native-diagnostic.txt
  in the working folder (exit 2 when a validated game scene is unavailable).
  Noctra.exe --smoke-test checks ten seconds of native menu rendering with aiming
  disabled. Diagnostic reports may reveal game/client details; review before sharing.
